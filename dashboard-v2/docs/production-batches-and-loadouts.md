# Production batches and named builds

The merchant retains a production destination across loop ticks. Xyn exchanges
drain first unless the merchant is already at the upgrade NPC with actionable
work. Compounds and upgrades then drain without a return to the stand between
attempts. Each attempt re-reads inventory; missing scrolls, inventory space,
configured gold limits, death or an explicit bank deposit release the batch.
Stand postings, stock purchases and farmer delivery trips cannot take over a
production destination. Immediate allowlisted bank deposits retain priority.

Named builds are cloned in Farming → Equipment & skills. The ID is shared by
all farmers, while each character retains its own gear and skills copied from
the selected build. Names use letters, digits, underscores and hyphens. Named
builds appear in farming, hunts, recurring bosses, events, activity profiles and
build comparison. The cloned base (AOE/single-target/tank) determines default
skill behavior when the skill list is empty. All named build items are protected
from inventory transfers. Save then deploy to activate a changed build.

During Franky events, the event router and farmer targeting filters accept
Franky as the attack objective, excluding surrounding One Eyes. This also
prevents the warrior's defensive target priority from overriding the objective.
Healing remains available.
